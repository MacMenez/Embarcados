## ESP-IDF

Acessando o [Site Espressif](https://www.espressif.com/), na seção de SDK, escolha **ESP-IDF**. Navegue pela página até encontrar a seção **Get Started with ESP-IDF** e selecione o **Getting Started Guide**. Encontrado também [aqui](https://idf.espressif.com/).
Esta página conterá todas as familias atuais da Espressif, se a intenção for instalar para todas as famílias atuais (como é o caso), escolha a primeira opção, **ESP32 Series**. Ao escolher esta opção, haverá um direcionamento para a página oficial da documentação, **Get Started**.   Navegando pela página, há a opção de seleção por pulg-in através da IDE Eclise e/ou VS Code. Há também a opção de instalação manual, no caso selecionando o instalador para Windows e/ou Linux.  
Selecionando a opção *Windows Installer*, haverá diversas opções para selciona, dentre elas um instalador online, para ser baixado durante a insalação, mas também há a opção de baixar a opção de instalador padrão, para quando não há rede por exemplo. Optei pela 1°versão (cor verde), instalador online.  

1. Selecione o idioma desejado;
2. Leia a licensa, só é permitido continuar se marcar a opção de aceitar;
    * Haverá uma verificação no computador para identificar ferramentas necessárias, configurações internas de ambiente, etc;
3. Selecione a opção para Download;
4. Selecione a versão desejada (recomendado sempre a mais recente);
5. Endereço de instalação é opcional (pode deixar o padrão);
6. Selecione a gosto o que deseja que seja instalado. Importante selecionar a opção **Espressif IDE**. Atenção para as opções de selecionar as famílias, caso queira colocar ou retirar alguma que vá (ou não) utilizar. Optei por deixar desmarcado a opção de otimização *Git Mirror*;
7. Verifique o resumo de instalação. Concluído, instale. *Atenção pois poderá ser solicitado autorizações para instalar drivers e etc*;
